## 🔍 2단계 : "나만의 TCP 포트 스캐너 (Port Scanner)"

특정 서버(예: localhost)의 어떤 문(Port)이 열려 있는지 확인하는 보안 도구를 만들어봅시다. Go의 `net` 패키지를 사용하면 아주 적은 코드로 강력한 네트워크 도구를 만들 수 있습니다.

### 1. 학습 목표

-   **네트워크 프로그래밍:** `net.Dial` 함수를 사용하여 서버에 연결을 시도하는 법을 배웁니다.
-   **성능 체감:** 처음에는 한 줄씩 검사(Sequential)하게 만들고, 나중에 얼마나 느린지 확인합니다. (이게 3단계 병렬 처리의 명분이 됩니다.)
-   **사용자 입력 및 반복문:** 특정 범위(예: 1번~1000번)의 포트를 순회하며 검사합니다.

---

### 2. 프로젝트 구현 계획

**[1단계: 단일 포트 연결 테스트]**

-   `net.Dial("tcp", "localhost:80")` 명령어를 사용해 특정 포트가 열려 있는지 확인합니다.
-   에러(`err`)가 발생하면 포트가 닫힌 것이고, 없으면 열린 것입니다.

**[2단계: 포트 범위 순회]**

-   `for` 문을 사용해 1번부터 1024번(혹은 사용자가 지정한 범위)까지 포트를 하나씩 검사합니다.
-   연결 시도 시간이 너무 길어지지 않게 타임아웃(`net.DialTimeout`)을 설정하는 법을 익힙니다.

**[3단계: 깔끔한 결과 리포트]**

-   스캔이 끝난 후 "열려 있는 포트: 80, 443, 8080" 처럼 결과를 정리해서 보여줍니다.

---

### 3. 코드 가이드 (Skeleton)

이 코드를 바탕으로 포트 범위를 스캔하는 기능을 완성해 보세요.

```go
package main

import (
	"fmt"
	"net"
	"time"
)

func main() {
	address := "127.0.0.1" // 검사할 대상 (본인 컴퓨터)

	fmt.Printf("%s 포트 스캔을 시작합니다...\n", address)

	for port := 1; port <= 1024; port++ {
		// 주소 만들기 (예: "127.0.0.1:80")
		target := fmt.Sprintf("%s:%d", address, port)

		// 1. net.DialTimeout으로 연결 시도 (너무 오래 걸리지 않게 500ms 정도만 기다림)
		conn, err := net.DialTimeout("tcp", target, 500*time.Millisecond)

		if err != nil {
			// 에러가 나면 포트가 닫혀있는 것임 (그냥 넘어감)
			continue
		}

		// 2. 연결에 성공했다면 포트가 열려있는 것!
		conn.Close()
		fmt.Printf("[+] 포트 %d번이 열려 있습니다.\n", port)
	}

	fmt.Println("스캔이 완료되었습니다.")
}

```

---

### 💡 이번 과제의 포인트

-   **연결 시도(Dial):** 네트워크의 기본인 TCP 핸드셰이크가 성공하는지 체크하는 원리를 이해합니다.
-   **속도 체감:** 1번부터 1000번까지 검사하는 데 시간이 얼마나 걸리나요? 아마 생각보다 **매우 느릴 것**입니다. (하나씩 순서대로 기다려야 하니까요.)
-   **개선 포인트:** 이 "답답함"을 느끼는 것이 이번 과제의 핵심입니다. 이걸 아주 빠르게 만드는 게 바로 3단계의 주제거든요.

**이 스캐너를 실행해서 본인 컴퓨터의 열린 포트를 1개라도 찾아내셨나요?** 성공하셨다면 바로 알려주세요. 이제 이 도구를 100배 빠르게 만드는 **'고루틴(Goroutine)'의 마법**을 쓰러 가겠습니다!
