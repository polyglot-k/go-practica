## 🔍 3단계: 병렬 파일 내용 검색기 (Parallel Grep)

이 프로젝트는 파일 시스템 탐색과 고루틴 간의 데이터 통신(채널)을 결합한 실전형 과제입니다.

### 1. 요구사항 (자세하게)

1. **사용자 입력:**

-   검색을 시작할 **루트 디렉토리** 경로.
-   찾고자 하는 **키워드**(문자열).

2. **핵심 로직 (고루틴 활용):**

-   디렉토리를 재귀적으로 탐색하면서 파일을 하나 찾을 때마다 **새로운 고루틴**을 생성하여 파일 내용을 읽습니다.
-   각 고루틴은 파일 내부에 키워드가 있는지 검사합니다.

3. **결과 수집 (채널 활용):**

-   키워드를 찾은 경우, **[파일명: 라인번호: 라인내용]**을 채널로 전송합니다.
-   메인 함수는 채널을 통해 들어오는 결과들을 실시간으로 화면에 출력합니다.

4. **제한 사항 (고급):**

-   너무 많은 파일을 동시에 열면 시스템 에러가 날 수 있으므로, **Worker Pool** 패턴을 사용하여 동시에 작업하는 고루틴 개수를 제한해 보세요(예: 최대 100개).

---

### 2. 프로젝트 설계 계획

1. **[1단계] 파일 목록 수집:** 먼저 특정 폴더 안의 모든 파일 경로를 리스트로 만듭니다.
2. **[2단계] 검색 함수 작성:** 파일 경로와 키워드를 받아서 한 줄씩 읽으며 검색하고, 결과를 구조체로 반환하는 함수를 만듭니다.
3. **[3단계] 고루틴 적용:** 파일을 찾을 때마다 고루틴을 띄워 검색 함수를 실행합니다.
4. **[4단계] 채널 동기화:** 모든 고루틴이 끝날 때까지 기다린 후 프로그램을 종료하도록 `sync.WaitGroup`을 설정합니다.
